## 后端服务 (ai-service)

### 1. IntentService - 意图识别服务
**文件**: `ai-service/src/services/intentService.ts`
- 基于关键词和正则模式的规则匹配
- 支持 LLM 辅助分类（可选）
- 识别三种意图：`pipeline_generate` / `pipeline_edit` / `none`
- 置信度计算和阈值控制

### 2. TemplateService - 模板管理服务
**文件**: `ai-service/src/services/templateService.ts`
- 内置 6 个模板：通用、数据库同步、数据库导出、文件导入、文件转换、API 集成
- 模板变量校验和渲染
- 根据需求自动推荐模板

### 3. DocParser - 节点文档解析器
**文件**: `ai-service/src/services/docParser.ts`
- 内置 14 个节点规格（输入 5 个、转换 7 个、输出 4 个）
- 支持 Markdown/YAML 格式解析
- 节点搜索和匹配功能

### 4. GraphBuilder - DAG 构建服务
**文件**: `ai-service/src/services/graphBuilder.ts`
- 需求分析和实体提取
- 节点匹配和参数填充
- 拓扑排序和环路检测
- 自动布局计算

### 5. Validator - Pipeline 验证服务
**文件**: `ai-service/src/services/validator.ts`
- 语法校验（JSON Schema）
- 结构校验（节点、边完整性）
- 逻辑校验（DAG 无环、类型匹配）
- 参数验证（必填、枚举、正则）
- 自动修复功能

### 6. Agent API 路由
**文件**: `ai-service/src/handlers/agentHandlers.ts`

| API | 说明 |
|-----|------|
| `POST /agent/intents` | 意图识别 |
| `POST /agent/generate` | Pipeline 生成 |
| `POST /agent/validate` | Pipeline 验证 |
| `GET /agent/templates` | 获取模板列表 |
| `GET /agent/templates/:id` | 获取模板详情 |
| `GET /agent/nodes` | 获取节点库 |
| `GET /agent/nodes/:id` | 获取节点详情 |
| `POST /agent/preview` | 生成可视化布局 |

## 前端更新

### AIService - Agent API 调用
**文件**: `jupyterlab-amphi/packages/pipeline-editor/src/ai/AIService.ts`
- `recognizeIntent()` - 意图识别
- `agentGeneratePipeline()` - Agent 生成 Pipeline
- `validatePipeline()` - Pipeline 验证
- `getTemplates()` / `getNodes()` - 获取模板和节点库

### AIChatModal - 意图识别和生成流程
**文件**: `jupyterlab-amphi/packages/pipeline-editor/src/ai/AIChatModal.tsx`
- 发送消息时先进行意图识别
- 置信度不足时提示用户明确需求
- 支持 Agent API 和传统 API 两种生成方式
- 显示验证结果和修复建议

## 使用方式

1. 安装新依赖：
```bash
cd ai-service
npm install
```

2. 重启后端服务：
```bash
npm run dev
```

3. 重新编译前端后测试

## 示例请求

```bash
# 意图识别
curl -X POST http://localhost:3000/agent/intents \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "创建一个从 MySQL 读取数据到 CSV 的 Pipeline"}]}'

# Pipeline 生成
curl -X POST http://localhost:3000/agent/generate \
  -H "Content-Type: application/json" \
  -d '{"requirement": "从 MySQL 读取用户表数据，导出为 CSV 文件", "useLLM": false}'
```
