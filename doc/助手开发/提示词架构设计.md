系统提示词架构，实现分层设计：

1. **核心系统提示词**（最高优先级）- 内置不可修改
2. **Pipeline Agent 专用提示词**（中优先级）- 用于 Pipeline 生成
3. **用户自定义提示词**（最低优先级）- 可选补充


**以下是实现的架构：**

## 系统提示词层级设计

### 1. 核心系统提示词（最高优先级）
```
CORE_SYSTEM_PROMPT - 内置不可修改
- 定义 AI 助手的角色和职责
- 设定对话规则（如问候语不触发 Pipeline 生成）
- 明确能帮助的范围
```

### 2. 场景专用提示词（中优先级）

**普通对话 (`CHAT_SYSTEM_PROMPT`)**:
- 继承核心提示词
- 添加可用组件参考列表
- 指导如何引导用户描述需求

**Pipeline 生成 (`PIPELINE_AGENT_SYSTEM_PROMPT`)**:
- 继承核心提示词
- 详细的 `.ampln` JSON 格式规范
- 所有可用组件类型及参数说明
- 生成规则和示例
- 降低 temperature 至 0.2 以获得更稳定的 JSON 输出

### 3. 用户自定义提示词（最低优先级）
- 可选补充，追加在末尾
- 用户可清空，不影响正常使用
- 格式：`## 用户自定义补充说明\n{用户输入内容}`

## 日志输出示例

**普通对话时**:
```
[Chat Handler] 系统提示词构建完成
[Chat Handler] - 内置提示词长度: 1250
[Chat Handler] - 用户自定义: 50 字符
```

**Pipeline 生成时**:
```
[Chat Handler] Pipeline Agent 系统提示词构建完成
[Chat Handler] - Pipeline Agent 提示词长度: 3200
[Chat Handler] - 用户自定义补充: (无)
[Chat Handler] - 最终提示词长度: 3200
```

## 效果

1. **"你好"** → 使用 `CHAT_SYSTEM_PROMPT`，友好回应，不生成 Pipeline
2. **"从 MySQL 读取用户表导出 CSV"** → 使用 `PIPELINE_AGENT_SYSTEM_PROMPT`，精确生成 Pipeline JSON
3. **用户自定义提示词** → 作为补充追加，不覆盖内置提示词
