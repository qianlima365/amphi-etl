为对话框添加 Markdown 渲染支持。

## 新增 MarkdownRenderer 组件

```typescript
const MarkdownRenderer: React.FC<{ content: string }> = ({ content }) => {
  const html = useMemo(() => {
    // 转义 HTML 特殊字符（安全性）
    // 代码块渲染（暗色主题）
    // 行内代码（高亮显示）
    // 标题 (# ## ###)
    // 粗体 (**text**)
    // 斜体 (*text*)
    // 链接 [text](url)
    // 列表（有序/无序）
    // 分隔线 (---)
    // 换行处理
  }, [content]);
  return <div dangerouslySetInnerHTML={{ __html: html }} />;
};
```

## 支持的 Markdown 语法

| 语法 | 示例 | 效果 |
|------|------|------|
| 标题 | `# 标题` `## 二级` `### 三级` | 不同大小的标题 |
| 粗体 | `**粗体**` 或 `__粗体__` | **粗体** |
| 斜体 | `*斜体*` 或 `_斜体_` | *斜体* |
| 代码块 | ` ```python\ncode\n``` ` | 暗色代码块 |
| 行内代码 | `` `code` `` | 高亮代码 |
| 链接 | `[文本](url)` | 可点击链接 |
| 无序列表 | `- 项目` 或 `* 项目` | • 项目 |
| 有序列表 | `1. 项目` | 1. 项目 |
| 分隔线 | `---` 或 `***` | 水平线 |

## 消息显示逻辑

```
用户消息 → 纯文本 <pre> 显示（保持原样）
助手消息 → Markdown 渲染（支持格式化）
加载状态 → "💬 回复中..." 动画
```

## 样式特点

- **代码块**：暗色背景 (#1e1e1e)，浅色文字，圆角边框
- **行内代码**：浅灰背景，粉色文字
- **标题**：加粗，不同字号
- **链接**：蓝色，新窗口打开
- **安全性**：HTML 特殊字符已转义，防止 XSS



增强 Markdown 渲染器：添加引用块、为列表包裹 `<ul>`/`<ol>`，并修正处理顺序与代码块内换行显示。

修正代码块内的二次转义：全文已转义，代码块内不应再转义。


**1. 引用块**  
- 支持 `> 引用内容`，渲染为左侧蓝色竖线 + 灰色背景的块引用。

**2. 列表结构**  
- **无序列表**：连续多行 `- item` / `* item` 会包在同一个 `<ul>` 里。  
- **有序列表**：连续多行 `1. item` 会包在同一个 `<ol>` 里。  
- 列表样式（缩进、符号）已统一。

**3. 代码块**  
- 为 `<pre>` 增加 `white-space: pre-wrap` 和 `word-break: break-word`，长代码会换行且不撑破布局。  
- 代码块内容只依赖全文的一次 HTML 转义，避免重复转义导致显示异常。

**4. 行内代码**  
- 行内代码的正则改为不匹配含换行的内容（`[^`\n]+`），避免误伤多行代码块。

**5. 换行清理**  
- 在块级元素（如 `</blockquote>`、`</ul>`、`</ol>`）后的多余 `<br>` 会被去掉，避免多余空行。

**6. 容器样式**  
- Markdown 根节点增加 `wordBreak: 'break-word'`，长链接或长单词会自动换行。

当前支持的 Markdown 包括：标题、粗体、斜体、行内代码、代码块、无序/有序列表、链接、引用、分隔线；助理回复会按上述规则渲染，用户消息仍为纯文本。
