优化对话框接口，后台自动判断意图并决定是普通回复还是生成 Pipeline。


### 1. 新增统一对话接口 (后端)

**文件**: `ai-service/src/handlers/chatHandler.ts`

- **路由**: `POST /agent/chat`
- **功能**: 自动识别用户意图
  - 普通对话 → 直接调用 LLM 回复
  - Pipeline 生成 → 调用 Agent 生成 Pipeline
- **返回格式**:
```typescript
{
  success: boolean;
  message: string;           // 回复内容
  intent: {
    type: 'pipeline_generate' | 'chat' | 'none';
    confidence: number;
  };
  pipeline?: AmplnSchema;    // 仅生成 Pipeline 时返回
  validation?: {...};        // 验证结果
  metadata?: {...};          // 元信息
}
```

### 2. 前端 AIService 新增方法

**文件**: `jupyterlab-amphi/packages/pipeline-editor/src/ai/AIService.ts`

```typescript
static async chat(
  messages: Array<{ role: 'user' | 'assistant' | 'system'; content: string }>,
  options?: {
    model?: { providerId, model, apiKey, ... };
    systemPrompt?: string;
  }
): Promise<ChatResponse>
```

### 3. 前端对话框优化

**文件**: `jupyterlab-amphi/packages/pipeline-editor/src/ai/AIChatModal.tsx`

改动：
- **统一调用入口**: 所有消息都通过 `/agent/chat` 发送
- **智能进度条**: 只有生成 Pipeline 时才显示进度条
- **普通对话无进度条**: 直接显示 LLM 回复

## 工作流程

```
用户发送消息
    ↓
后端接收 → 意图识别
    ↓
┌─────────────────┬─────────────────┐
│  普通对话       │  Pipeline 生成   │
│  (chat/none)    │  (pipeline_*)   │
└────────┬────────┴────────┬────────┘
         ↓                  ↓
    LLM 直接回复      Agent 生成 Pipeline
         ↓                  ↓
    返回 message      返回 message + pipeline
         ↓                  ↓
前端显示回复        前端显示回复 + 预览
(无进度条)          (有进度条)
```

## 示例

**普通对话** (无进度条):
```
用户: 你好，介绍一下 Amphi ETL
助手: Amphi ETL 是一个数据管道构建平台...
```

**Pipeline 生成** (显示进度条):
```
用户: 创建一个从 MySQL 读取数据到 CSV 的 Pipeline
助手: Pipeline 生成成功！
      节点数: 2
      连接数: 1
      生成方式: 规则引擎
      [预览 Pipeline]
```
