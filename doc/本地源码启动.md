```
uv venv
source .venv/bin/activate
<!-- 或 .venv\Scripts\activate -->
uv pip install -U "jupyterlab>=4,<5" "hatch-jupyter-builder>=0.9"
uv pip install -e ./amphi-scheduler
uv pip install -e ./amphi-etl
```

- 启动应用（两种方式二选一）
  - 如果已生成 console 脚本 amphi：
    ```
    amphi start -w . -p 8888
    ```
  - 若未生成 amphi（依赖 setup.py，某些环境可能被 pyproject 流程忽略），用 Python 入口直接启动：
    ```
    python -m amphi.main start -w ./data -p 8888
    python -m amphi.main start -w ./data -p 8888 --allow-lan --allow-embed  --no-auth
    ```
    备注：--allow-lan 允许局域网访问本机，--allow-embed 允许嵌入iframe，--no-auth 允许匿名访问
说明：
- amphi CLI 的实现见 main.py ，本质是以指定工作目录启动 JupyterLab 并加载扩展。
- amphi-scheduler 会把服务器扩展配置写入 Jupyter 的 etc/jupyter/jupyter_server_config.d（参见 amphi-scheduler pyproject 的 shared-data ，配置内容见 amphi-scheduler.json ）；JupyterLab 启动后自动加载该扩展。
