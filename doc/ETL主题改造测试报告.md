# ETL 组件 Neon Future 主题改造 - 测试报告

本文档为样式改造后的功能与视觉回归清单，确保与现有功能完全兼容。

---

## 1. 测试环境建议

- 浏览器：Chrome / Edge 最新版；可选 Safari、Firefox。
- 分辨率：1920×1080、1366×768、375×667（移动端）。
- 主题：先测 **Light** 再测 **Neon Future**（切换后刷新或重新打开 Pipeline 页）。

## 4. 主题变量维护验证

|------|------|

## 5. 已知限制与说明

- **Edge 颜色**：若 React Flow 对边的 `stroke` 使用内联样式，Neon 主题下边线颜色可能需在运行时通过 theme 传入 `style` 覆盖；当前以 CSS 覆盖为主。
- **截图对比**：不同主题下的视觉对比请按《ETL组件样式规范》第 8 节进行截图留存。
