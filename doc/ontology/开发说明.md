# 本体管理开发说明

## 已完成的开发（Phase 1–3 部分）

### 1. 功能文档与技术选型

- **功能规划**：`doc/ontology/本体管理功能规划.md`
- **技术选型**：`doc/ontology/本体管理技术选型.md`

### 2. 后端（ai-service 内嵌本体模块）

- **图库**：Neo4j，通过 `neo4j-driver` 连接。
- **模块位置**：`ai-service/src/ontology/`
  - `model.ts`：节点/关系类型常量与 DTO
  - `neo4j.ts`：驱动单例与会话封装
  - `service.ts`：组件/参数/关系 CRUD、图数据、搜索、按输入输出类型查组件
  - `importFromMetadata.ts`：解析 `components-metadata.md` 并导入 Neo4j
- **路由**：`ai-service/src/handlers/ontologyHandlers.ts`，挂载在 `/ontology/*`。
- **环境变量**（可选）：`NEO4J_URI`、`NEO4J_USER`、`NEO4J_PASSWORD`。未配置时 `/ontology/*` 返回 503。

### 3. 管理端前端（ontology-admin）

- **技术栈**：Vite + React + TypeScript + Ant Design + React Flow
- **位置**：`ontology-admin/`
- **功能**：图可视化、组件列表、搜索（调用 ai-service 的 `/ontology/*`）。
- **启动**：在 `ontology-admin` 下执行 `npm run dev`，默认端口 3002，通过 Vite proxy 访问 ai-service。

## 本地运行顺序

1. **启动 Neo4j**（若使用 Docker）：
   ```bash
   docker run -d -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/password neo4j
   ```

2. **配置 ai-service**：在 `ai-service` 下创建 `.env`，增加：
   ```env
   NEO4J_URI=bolt://localhost:7687
   NEO4J_USER=neo4j
   NEO4J_PASSWORD=password
   ```

3. **启动 ai-service**：
   ```bash
   cd ai-service && npm install && npm run dev
   ```

4. **导入初始数据**（可选）：向 `POST /ontology/import` 发送 body `{ "markdown": "..." }`（将 `components-metadata.md` 内容粘贴），或使用 `filePath` 指定服务端路径。

5. **启动管理端**：
   ```bash
   cd ontology-admin && npm install && npm run dev
   ```
   打开 http://localhost:3002，使用「图可视化」「组件列表」「搜索」标签页。
